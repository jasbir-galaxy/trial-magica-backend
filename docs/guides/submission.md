## Before recording

- Merge reviewed changes, wait for Vercel, and deploy the matching Trigger worker.
  Record both source commits and the worker version with the acceptance evidence.
- Complete the remaining checks in [hosted acceptance](hosted-acceptance.md).
  Fixtures and local runs do not substitute for hosted success evidence.
- Verify reviewer sign-in from a signed-out browser. Share any dedicated reviewer
  access privately; never put passwords, API keys, or authentication state in Git.
- Select your own media files for the upload demonstration. Keep private files,
  account keys, and service dashboards out of the recording.
- Open the saved successful image/crop chain and merged-video conversation before
  recording. Identify them as saved real runs, rather than implying an accelerated
  recording shows live generation speed.
