# Visual brief

Write a short brief with these fields: subject and purpose; composition and framing; palette and lighting; style; text to include verbatim; and user-requested output settings. Mark unspecified settings as unspecified rather than inventing them.

For edits, identify what changes and what must remain. A color-change request should keep the supplied composition unless the user also requests a redesign. Use one image unless the user asks for more. Ask about material ambiguity before submitting a tool, and show the tool's actual settings in its approval card.
