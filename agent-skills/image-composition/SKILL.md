# Image composition

Translate the user's request into subject, framing, style, colors and output settings. Preserve explicit choices such as quality, dimensions and image count. If only planning is requested, provide the brief without generating media.

For generation, choose the text variant. When modifying a supplied image, choose the edit variant and preserve the user's source. Read `guides/brief.md` when a structured visual brief would help. Use current tool schema fields; do not invent settings or infer that a missing quality choice is cheap.

Loading this skill does not authorize execution. Use the ordinary image tool, which enforces ownership, funding and approval. Inspect its returned asset and actual settings before describing the result. Never claim that a requested setting was applied when the tool input or result says otherwise. Do not call a media tool when the user only asked for advice or a plan.
