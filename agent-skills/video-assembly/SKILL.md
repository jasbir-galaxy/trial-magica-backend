# Video assembly

Collect between two and one hundred source video URLs in the user's intended order. Preserve that order exactly. If only a plan is requested, return the sequence without submitting work. Never invent clips or reuse a prior generated image URL as a video.

Read `guides/transitions.md` when transition selection or a preflight checklist would help. The current merge tool supports none, fade and dissolve. Ask the user to resolve missing sources or ambiguous ordering before execution.

Use the ordinary merge tool; guidance cannot bypass approval, ownership or funding checks. After completion, provide the actual returned video URL. Describe only settings present in validated inputs and avoid promising frame-perfect cuts, audio mixing or duration behavior that the contract does not provide.
